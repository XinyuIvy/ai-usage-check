# Security

Do not report exposed credentials in a public issue. Use GitHub's private security advisory feature for this repository.

The dashboard must remain private. The recommended configuration binds normal access to the computer and exposes it only through Tailscale Serve. Never use Tailscale Funnel, router port forwarding, or a public reverse proxy for this project.

Only quota numbers are cached on the phone. Claude, OpenAI, and Google credentials remain on the computer where their CLIs are logged in.
